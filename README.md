# Notification-network 🌐📬

โปรแกรมสคริปต์ Python สำหรับตรวจสอบสถานะเครือข่าย (Network Connectivity) โดยการ Ping ไปยัง DNS และส่งรายงานหรือแจ้งเตือนผลลัพธ์เข้าอีเมล Gmail โดยอัตโนมัติ

## 🚀 ฟีเจอร์หลัก (Features)
- 🏓 ตรวจสอบสถานะการเชื่อมต่อเครือข่ายด้วยการ Ping
- ✉️ ส่งรายงานผลลัพธ์และแจ้งเตือนตรงสู่ Gmail
- 🐍 พัฒนาด้วยภาษา Python ใช้งานง่ายและปรับแต่งได้สะดวก
